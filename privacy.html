プライバシーポリシー

最終更新日：2026年8月12日

Tony & Ryosuke（トニー＆りょうすけ、以下「当方」）は、当ウェブサイト （tonyandryo.com）および当方が運営する各種SNSアカウント、ならびに当方が自己の アカウント管理のために利用する内部ツールにおける個人情報の取扱いについて、 以下のとおり定めます。

1. 収集する情報

当ウェブサイトは、閲覧者から個人を特定できる情報を収集しません。フォーム、 ログイン機能、コメント機能は設置していません。

アクセス状況の把握のため Cloudflare Web Analytics を利用しています。同サービスは Cookie を使用せず、個人を特定する情報や端末を横断した追跡情報を収集しません。 取得されるのは、閲覧されたページ、参照元、おおまかな地域、ブラウザの種類といった 集計情報のみです。

2. 内部の分析ツールについて

当方は、自らが保有するSNSアカウント（YouTube、Instagram、X、TikTok、Threads、 LinkedIn、note）のフォロワー数など、公開されている集計値を記録するための内部 ツールを運用しています。

  • 取得するのは、当方自身のアカウントの合計フォロワー数などの統計値のみです。
  • フォロワー個人の情報、投稿内容、メッセージ、その他の個人データは取得しません。
  • 取得したデータは当方の非公開の記録に保存され、第三者に提供・販売しません。
  • 各プラットフォームへのアクセスは、当方自身のアカウントに対する読み取りのみで、 投稿・変更は行いません。

3. お問い合わせ情報

メールでお問い合わせいただいた場合、返信および記録の目的で、その内容および メールアドレスを保管します。当方から営業目的の連絡を行うことはなく、 第三者への提供も行いません。

4. 第三者サービス

当ウェブサイトは各種SNSへのリンクを掲載しています。リンク先での個人情報の 取扱いについては、各サービスのプライバシーポリシーが適用されます。当ウェブサイトは GitHub Pages 上でホストされ、Cloudflare を経由して配信されています。

5. データの保存期間

アクセス解析の集計データは Cloudflare Web Analytics の保存期間に従います。 SNSの統計値の記録は、当方が保有する限り保管します。お問い合わせのメールは、 必要がなくなった時点で削除します。

6. お問い合わせ窓口

本ポリシーに関するご質問、または当方が保有する情報の削除のご依頼は、 info@tonyandryo.com までご連絡ください。

7. 本ポリシーの変更

本ポリシーは必要に応じて改定することがあります。改定した場合は、本ページの 最終更新日を更新します。
